# Arc風スクリーンショット＆プレビュー（Chrome拡張機能）

Arcブラウザの便利な機能を Google Chrome で使えるようにする拡張機能です。

**スクリーンショット**
- **要素ごとの自動認識**：マウスを動かすと、カーソル下のHTML要素（画像・カード・ブロックなど）に枠線が表示され、クリックするだけでその要素だけを綺麗に切り抜けます。画面より縦に長い要素は自動でスクロールしてつなぎ合わせます。
- **範囲指定ドラッグ**：任意の場所をドラッグすると、通常の矩形選択スクリーンショットになります。

撮影した画像は自動でクリップボードにコピーされ、右下のカードから「保存」（PNGでダウンロード）やプレビューもできます。

**リンクのプレビュー（ArcのPeek風）**
- リンクを `⌘ + Shift + クリック`（Windowsは `Ctrl + Shift + クリック`）すると、今のページを離れずに、リンク先を上に重ねたウィンドウで表示します。

## インストール方法

1. このリポジトリをダウンロード（`Code` → `Download ZIP` して解凍、または `git clone`）
2. Chromeで `chrome://extensions` を開く
3. 右上の **デベロッパーモード** をオンにする
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、このフォルダ（`manifest.json` があるフォルダ）を選択
5. ツールバーのパズルアイコンから「Arc風スクリーンショット＆プレビュー」をピン留めしておくと便利です

すでに読み込んでいる場合は、`chrome://extensions` で拡張機能の更新ボタン（↻）を押し、開いているタブを再読み込みしてください。

## 使い方

### スクリーンショット

| 操作 | 内容 |
| --- | --- |
| ツールバーのアイコン / `⌘ + Shift + 2`（Mac）/ `Ctrl + Shift + 2`（Windows） | 撮影モード開始（もう一度押すとキャンセル） |
| マウスを動かす | 要素を自動認識して枠線表示 |
| クリック または `Enter` | 枠線の要素を撮影 |
| ドラッグ | 選んだ範囲を撮影 |
| `↑` / `↓` | 一回り大きい親要素 / 元の子要素に切り替え |
| `Esc` または右クリック | キャンセル |

ショートカットは `chrome://extensions/shortcuts` で変更できます。

### リンクのプレビュー

| 操作 | 内容 |
| --- | --- |
| リンクを `⌘ + Shift + クリック`（Mac）/ `Ctrl + Shift + クリック`（Windows） | プレビューを開く |
| プレビュー内のリンクを同じ操作でクリック | そのリンクのプレビューに切り替え |
| 「新しいタブで開く」 | 今プレビューで見ているページをタブで開く |
| 「URLをコピー」 | 今プレビューで見ているページのURLをコピー |
| `Esc` / ✕ / 外側の暗い部分をクリック | 閉じる |

## 補足

- `chrome://` で始まるページや Chrome ウェブストアなど、Chromeが拡張機能の動作を禁止しているページでは使えません（アイコンに × が表示されます）。
- 要素を撮るときは、固定ヘッダーなどが重ならないよう撮影中だけ一時的に非表示にします。
- ページ内の独立したスクロール領域の中にある長い要素は、画面に見えている分だけが撮影されます。
- プレビュー機能のため、インストール時にChromeが「すべてのサイト上にあるデータの読み取りと変更」の許可を求めます。リンクのクリックを検知するためで、データを外部に送ることはありません。
- 多くのサイトは「他のページの中に表示されること」を禁止していますが、プレビューを開いている間だけ、そのタブ内でこの制限を外して表示します。閉じると元に戻ります。
- プレビュー内ではログイン状態が引き継がれず、ログアウトした状態で表示されるサイトがあります。うまく表示されないときは「新しいタブで開く」を使ってください。
- `https` のページから `http` のリンクはプレビューできません（「新しいタブで開く」ボタンが表示されます）。
